# FadingToJosh's Stream Deck plugins

Help, documentation and issue tracking for my Stream Deck plugins. Source code isn't published here.

| Plugin | What it does | Help |
| --- | --- | --- |
| **GitHub Tracker** | Shows new commits and releases on the repositories you follow, and lets you mark them seen. | [Docs, token guide and demo](github-tracker/README.md) |

## Get help

- **Bug?** [Open a bug report](https://github.com/FadingToJosh/streamdeck-plugins/issues/new?template=bug_report.yml) and pick the plugin.
- **Idea or question?** [Open a feature request or question](https://github.com/FadingToJosh/streamdeck-plugins/issues/new?template=feature_request.yml).
- Please search [open issues](https://github.com/FadingToJosh/streamdeck-plugins/issues) first, and never paste tokens, passwords or other secrets.

## Privacy

Each plugin has its own privacy policy in its folder: [GitHub Tracker](github-tracker/PRIVACY.md).
