    What's simulated

    The plugin's detection, matching and drawing run unchanged. Underneath, the list of running programs, the game list and the icons come from this page instead of Windows and the internet. All games shown are fictional.

    How it works for real

    Every 5 seconds the plugin lists running programs and matches them against the public list of games that Discord recognizes. Discord doesn't need to be installed. If several games run, the most recently launched one wins.
