    What's simulated

    The keys are drawn by the plugin's own rendering code, so they look exactly like the real thing. The repos, the polling, and the browser links are faked. On a real deck, pressing a key with changes opens the compare view or releases page in your browser.

    Try it for real

    1. Create an empty public repo, e.g. tracker-playground.
    2. Add you/tracker-playground to a Repo Tracker key and set Check every to 5 minutes.
    3. Commit a file on github.com, or publish a release, and wait for the next check.

    How it counts

    When you add a repo, everything already there counts as seen. Commits on the default branch and releases are counted separately. Holding a key records the current state as seen.
