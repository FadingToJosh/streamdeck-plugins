# Privacy policy: Repo Watch for Stream Deck

Repo Watch is a Stream Deck plugin that tracks GitHub repositories. It is not affiliated with or endorsed by GitHub, Inc.

_Last updated: 2026-11-25_

Repo Watch does not collect, sell, or share any personal data, and it contains no analytics, telemetry, or ads.

**What it stores, and where.** The list of repositories you track, what you've marked as seen, your polling interval, your language choice, and (if you add one) your GitHub personal access token. All of it is kept in Stream Deck's own plugin settings on your computer. The token is never shown back in the settings panel and is never sent anywhere except GitHub.

**Who it talks to.** Only GitHub's public REST API (`api.github.com`), to read commits and releases for the repositories you added. Requests go directly from your computer to GitHub. GitHub's own privacy statement applies to those requests. Pressing a key opens a github.com page in your default browser.

**Deleting your data.** Remove a repo in the plugin's settings to delete its tracking state. Clear the token field to delete the token. Uninstalling the plugin from Stream Deck deletes everything it stored. You can also revoke the token at any time in your GitHub settings.

**Contact.** Questions or requests: open an issue at https://github.com/FadingToJosh/streamdeck-plugins/issues
